# Dotted Font Maker

Turn any font into a dotted version, right in the browser.

**Open it:** https://aneexs.github.io/dotted-font-maker/

1. Choose a `.ttf`, `.otf` or `.woff` font file.
2. Pick **Centre line** (one row of dots down the middle of each stroke, like a tracing worksheet) or **Outline** (dots along the edge of each letter).
3. Adjust the dot size and spacing, then download the dotted `.ttf`.

The font is converted inside your browser and is never uploaded. The dotted copy is renamed with "Dotted" added, so it installs alongside the original. Kerning, ligatures and accent positioning carry over.

Check that the original font's licence allows modified copies before you share the result.
